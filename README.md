# Rock Quest — นักสืบหินและแร่ 8 ด่าน

เกมคำถามเชิงภาพสำหรับนักเรียนอายุประมาณ 13 ปี เรียนรู้จากชุด PowerPoint นักสืบหินและแร่ทั้ง 8 ตอน

## ด่าน

1. หินอัคนี ตอนที่ 1
2. หินอัคนี ตอนที่ 2
3. หินตะกอน ตอนที่ 1
4. หินตะกอน ตอนที่ 2
5. หินแปร ตอนที่ 1
6. หินแปร ตอนที่ 2
7. แร่ ตอนที่ 1
8. แร่ ตอนที่ 2

แต่ละด่านมี 20 คำถาม ตัวเลือก A–E ภาพเดิมจะถูกนำกลับมาถามซ้ำด้วยรูปแบบ “ทายชื่อ” และ “ชี้ลักษณะเด่น” เพื่อเสริมความจำ ต้องได้อย่างน้อย 16/20 คะแนนเพื่อปลดล็อกด่านถัดไป หากไม่ผ่าน ความคืบหน้าจะถูกล้างและกลับไปเริ่มด่าน 1
